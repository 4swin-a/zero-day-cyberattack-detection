# Detection of Zero Day Cyberattack in Critical System

An academic cybersecurity project developed as part of my B.Sc. Cyber Forensics program.

The project focused on creating a web-based system for detecting and analyzing potential zero-day cyberattacks in critical systems using the MERN Stack.

## 📌 Project Overview

The objective of this project was to explore how a web-based application could be used to identify, analyze, and present information related to potential zero-day cyberattacks.

The application was developed using the MERN Stack:

- MongoDB
- Express.js
- React.js
- Node.js

## 🎯 Objectives

- Develop a web-based cybersecurity analysis platform
- Explore concepts related to zero-day cyberattacks
- Analyze potential attack-related information
- Present analysis results through a web interface
- Gain practical experience with full-stack web development
